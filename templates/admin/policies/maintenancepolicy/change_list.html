How to create a Maintenance Policy

  1. Make sure your Sites, Payloads, and Robots exist under Fleet.
  2. Optionally create a Checklist Template under Checklists.
  3. Click “Add maintenance policy” (top right).
  4. Fill Basics (name, type, priority) and choose Published when ready.
  5. Set Scope (Site, and optional tier/model/payload filters).
  6. Set Triggers (time cadence and/or usage hours).
  7. Attach Checklist Template and pick a Manager.
  8. Save. Work orders will be generated per cadence.
